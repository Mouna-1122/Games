# 🎮 Python Mini Games & Utilities

A collection of beginner-to-intermediate Python projects built to strengthen programming, logic building, and object-oriented programming skills. This repository contains classic games and utility applications developed using Python.

**Developer:** Mouna M

---

## 🛠 Tech Stack

- **Language:** Python 3
- **GUI:** Tkinter (for calculator projects)
- **Game Library:** Turtle (Snake)
- **Concepts:** OOP, Functions, Loops, Conditionals, Random Module

---

# 📂 Projects

| Project | Description |
|---------|-------------|
| 🐍 SnakeX | Classic Snake game built using Python Turtle graphics. |
| ✊ Rock Paper Scissors | Play against the computer with randomized moves. |
| 🎲 Dice Roller | Generates random dice rolls with each play. |
| 🎯 Guess the Number | Number guessing game with score and hints. |
| 🃏 BlackJack | Console-based Blackjack card game against the dealer. |
| ❌ Tic-Tac-Toe | Two-player Tic-Tac-Toe game in Python. |
| 🔤 HangMan | Word guessing game with limited lives. |
| ➕ Calculator | Basic arithmetic calculator. |
| 🧮 Scientific Calculator | Calculator supporting advanced mathematical operations. |

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Mouna-1122/python-mini-games.git
```

### Navigate to any project

```bash
cd SnakeX
```

### Run the application

```bash
python snake.py
```

> Replace the filename depending on the project.
